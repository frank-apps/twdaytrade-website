# 當沖計算機

[當沖計算機](https://frank-apps.github.io/twdaytrade-website/)（TW Day Trade Calc）是台股現股與 ETF 當沖試算 App 的說明站，內含介紹、操作說明、上架圖（`store/`）、隱私權與支援頁面。

## 這個 App 做什麼

- 輸入買進價和張數，看漲幾檔開始獲利，以及每一檔的損益。
- 從券商對帳單抄價金和手續費，反推折數，並可設成自己的手續費折數。
- 試算與折數存在這支手機上，沒有帳號。
